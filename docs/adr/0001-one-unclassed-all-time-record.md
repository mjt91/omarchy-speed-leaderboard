# One unclassed, all-time Record

Since Omarchy 3.0's offline ISO removed the network from the install path, install time is bound almost entirely to disk write speed and CPU — so the Record is, in honest terms, substantially a hardware contest. We nonetheless keep a single all-time Record across every version and every machine, with no hardware classes and no per-version records.

## Considered Options

Hardware classes (NVMe generation, laptop/desktop, bare metal/VM) were rejected because this community is small enough that classes would produce several categories holding one entry each, which reads as dead rather than competitive. Per-version records were rejected because they fragment the headline; the version story is carried by the Milestone history instead, where it belongs. A controlled "reference machine" strand — the same box timed across releases, the only rigorous way to claim "4.0 is 30% faster" — was considered and dropped as too much ongoing work for a fun project.

## Consequences

The site therefore cannot honestly claim to benchmark Omarchy's own speed; it records what people achieved, and the history narrates what the project achieved. Machine specs are displayed beside every entry so readers can interpret a time, but they never affect ranking. Adding classes later would retroactively invalidate the existing ranking, so this is expensive to reverse.
